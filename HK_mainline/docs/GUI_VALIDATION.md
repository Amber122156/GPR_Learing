# GUI 验证记录

本版用 MATLAB R2024a / Simscape 实际执行参数/UI 测试及整机仿真。结果索引为 `validation/gui_component_tests.json` 与 `validation/gui_simulation_tests.json`。

验证覆盖参数边界、非法 JSON、配置往返、原生 GUI 构造和赋值、扰动开启时增益一致、实际气动力核左右翼缩放、延迟取整、零电机延迟整机仿真、默认悬停、改变控制/翼误差/电机延迟/转速滞后/噪声后的整机仿真，以及手动中止和会话清理。

默认与改参工况各运行 5 s；这是本次 GUI 接入的数值验证，不等价于实机标定或所有增益组合的稳定性证明。中途停止测试检查日志结束时间，防止将部分飞行数据外推到设定时长。

`validate_mainline` 默认只检查专用悬停模型：0.2032 kg 总质量、各刚体惯量、包内几何路径、解析双翼运动，并执行已有四旋翼核心检查和新增 GUI 组件检查。`smoke_mainline` 只检查 1 s 零电机延迟运行。

新的发布包排除历史轨迹/脉冲/滤波工况与旧结果；包内 SHA-256 清单和 ZIP 内逐文件哈希验证支持传输完整性检查。
